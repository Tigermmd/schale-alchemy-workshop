# 国服礼物养成规划：待补数据问卷

这份问卷用于补充目前无法从中国服公开资料稳定确认、但会影响礼物养成规划计算的数据。请尽量按照**当前中国服实际游戏内规则**回答，并为关键数字附上截图、录屏、公告链接或可复核的实测记录。

这次改成问答形式，是因为很多规则不是一个数字能说清楚：例如奖励是否按档位变化、两个咖啡厅是否分别计算、礼物盒到底是随机还是自选、制造节点选中后是否可能产出非礼物等。请直接用自然语言描述条件，不必为了适应格式而压缩信息。

## 填写方法

- 服务器固定为：中国服（CN）。
- 每道问题下都有“回答”“证据”“版本/日期”“补充说明”四个空位。没有把握时请直接写“未知”，不要猜测。
- 数量必须写清楚单位和周期，例如“每个账号每周”“每次活动”“每天”“每月重置后”“一次性”。
- 如果规则因活动、难度、排名、学生版本或维护日期而不同，请把不同情况分别写出来。
- 来源优先级：游戏内截图/录屏 > 国服官方公告 > 国服客户端数据 > 可复核的国服攻略/社区记录。
- 规划器会把未知项保留为未知；**未知项不会自动计入期望**，也不会默认为 0。已确定的非礼物产出是例外：直接舍弃，按 0 好感值和 0 礼物数量处理。
- 你可以直接填写本 Markdown 文件，也可以把截图、录屏和文字回答一起发回。我会根据回答更新 JSON 数据、重新计算期望，并保留数据来源和适用版本。
